# AI Usage Policy

We want every team to use AI tools productively and safely. This policy covers both using AI assistants at work and building AI features into our products.

## Approved tools

Only AI tools on the approved list in the IT portal may be used with company data. Customer personal data and secrets must never be pasted into tools that are not on the approved list.

## AI-assisted code

AI-generated code is held to the same standard as any other code: it needs a passing CI run and a human review under the normal code review guidelines. The author is responsible for code they submit, regardless of how it was written.

## Building AI features

Every AI feature that reaches customers needs a risk review with the AI Council before launch. The review covers intended use, failure modes, data handling and a rollback plan.

## Evaluations

AI features must have an evaluation suite before launch. Any change to a model, prompt or retrieval configuration must be run against the evaluation suite, and the results attached to the pull request, before it reaches production.

## Transparency

Customer-facing content generated by AI must be labeled as AI-generated.
